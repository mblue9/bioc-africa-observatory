# Bioconductor Africa Observatory

This repository contains aggregated, country-level maps for the Bioconductor Africa Seminar Series.

The site currently includes:

- a global map of registrants by country  
- an Africa-focused view of the same data  

## Data

This project uses aggregated country-level counts of registrants and participants.

Raw registration or attendance files are not included in this repository and should be kept locally in `data-raw/`, which is ignored by git.
